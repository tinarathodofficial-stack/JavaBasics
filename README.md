# ⚡ JavaScript Basics — Interactive Learning Platform

Welcome to **JavaScript Basics**, a modern, interactive, and beginner-friendly web documentation portal built to teach the core fundamentals of JavaScript. 

The site guides learners through theoretical JS concepts alongside active **Live Workshop Playgrounds** where they can write and run code directly in the browser.

---

## 📚 Curriculum & Course Contents

Currently, the portal contains the following structured notes and chapters:

### 🟢 Active (Getting Started)
These chapters are visible on the sidebar for onboarding:
1. **Intro to JavaScript** (`1-intro.md`): Understanding the role of JavaScript in the Web Stack (HTML/CSS/JS analogy) and what it is used for.
2. **JavaScript Execution Environments** (`1-howItworks.md`): Comparing how JavaScript runs client-side in the browser vs. backend in the Node.js runtime environment.
3. **How JavaScript Works** (`1-howjsrun.md`): Introducing key engine concepts like compilation, execution contexts, and call stacks.
4. **Console Basics** (`1-consolebasics.md`): Leveraging the developer console and output options for testing.

### 🟡 Core Syntax & Advanced (Temporarily Hidden)
These advanced chapters are contained in the codebase but are currently hidden from the sidebar navigation:
- **Core Syntax**: Variables & Scope (`2-variables.md`) and Control Flow & Loops (`3-control-flow.md`).
- **Functions & Modules**: Functions & Return (`4-functions.md`).
- **Functions & Lists**: Arrays & Iteration (`5-arrays.md`).
